# 📖 ખાતાવહી (KhataVahi) - દુકાન માટે ડિજિટલ હિસાબ ચોપડો

તમારી દુકાન માટે ખાસ ગુજરાતી ભાષામાં અને મોબાઈલ-ફ્રેન્ડલી ડિઝાઇન સાથે બનાવેલી સંપૂર્ણ વેબસાઈટ.

---

## 🌟 મુખ્ય વિશેષતાઓ (Features)

### 👨‍💼 દુકાનદાર (Admin) માટે:
1. **સુરક્ષિત લૉગિન:** યુઝરનેમ અને પાસવર્ડથી લૉગિન, સેટિંગ્સમાંથી પાસવર્ડ બદલવાની સુવિધા.
2. **વસ્તુઓ અને ભાવ વ્યવસ્થાપન:** વસ્તુનું નામ, ભાવ (દા.ત. દૂધ ₹66) અને એકમ (લીટર, કિલો, નંગ) ઉમેરો, સુધારો કે કાઢો.
3. **ગ્રાહકોની યાદી:** નવો ગ્રાહક ઉમેરો (નામ, 10 અંકનો ફોન, 4 અંકનો PIN), દરેક ગ્રાહકની બાકી રકમ (લાલ/લીલા રંગમાં), WhatsApp રીમાઇન્ડર અને ખાતું કાઢવાની સુવિધા.
4. **નવી નોંધ (ઉધાર):** ગ્રાહક પસંદ કરો, વસ્તુ પસંદ કરો અને જથ્થો લખો. **રકમ = ભાવ × જથ્થો આપોઆપ ગણાઈ જાય છે** અને ગ્રાહકના ખાતામાં ઉધાર લખાય છે.
5. **પૈસા જમા કરો:** ગ્રાહક પૈસા આપે ત્યારે રોકડ (Cash) અથવા UPI/Google Pay થી જમા કરો, બાકી રકમ તરત ઘટી જશે.
6. **ડેશબોર્ડ:** આજનું કુલ વેચાણ (ઉધાર), આજની કુલ જમા, બજારમાં કુલ બાકી રકમ અને તાજેતરની નોંધો.
7. **નોંધ સુધારવી/કાઢવી:** કોઈપણ ભૂલ થાય તો ગ્રાહકના ખાતાવહી પેજ પરથી એન્ટ્રી એડિટ અથવા ડિલીટ કરી શકાય છે, અને બાકી રકમ તરત રીકેલ્ક્યુલેટ થાય છે.
8. **WhatsApp & પ્રિન્ટ:** ગ્રાહકને તેનો હિસાબ WhatsApp પર 1 ક્લિકમાં મોકલો અથવા પ્રિન્ટ/PDF કાઢો.

### 👤 ગ્રાહક (Customer) માટે:
1. **સરળ લૉગિન:** 10 અંકનો મોબાઈલ નંબર અને 4 અંકનો PIN દાખલ કરીને લૉગિન.
2. **પોતાનો જ હિસાબ:** 
   - તમારે દુકાને ચૂકવવાની બાકી રકમ (મોટા અક્ષરોમાં).
   - આજે લીધેલ સામાનની યાદી.
   - તારીખ મુજબ આખી ખાતાવહી (વસ્તુ, જથ્થો, રકમ, ઉધાર/જમા).
   - કુલ જમા કરેલ રકમ.
3. **100% ડેટા સુરક્ષા:** ગ્રાહક કોઈ બીજા ગ્રાહકનો ડેટા કોઈ પણ સંજોગોમાં જોઈ શકતો નથી (JWT ટોકન અને API લેવલ પર કડક આઈસોલેશન).

## 💻 કમ્પ્યુટર પર લોકલ ચલાવવાના સ્ટેપ્સ

### જરૂરી સોફ્ટવેર:
- **Node.js** (v20 અથવા v22+ ડાઉનલોડ કરો: [nodejs.org](https://nodejs.org))

### ૧. પ્રોજેક્ટ ફોલ્ડરમાં જવું:
કમાન્ડ પ્રોમ્પ્ટ (CMD) અથવા PowerShell ખોલો અને પ્રોજેક્ટ ફોલ્ડરમાં જાઓ:
```bash
cd "d:\ai arpan\manvata"
```

### ૨. પેકેજીસ ઇન્સ્ટોલ કરવા:
```bash
npm install --prefix server
npm install --prefix client
```

### ૩. વેબસાઈટ બિલ્ડ અને શરૂ કરવી:
```bash
# ફ્રન્ટએન્ડ બિલ્ડ કરો
npm run build

# સર્વર શરૂ કરો
npm start
```

### ૪. બ્રાઉઝરમાં ખોલો:
તમારા બ્રાઉઝરમાં નીચેની લિંક ખોલો:
👉 **`http://localhost:5000`**

## 🚀 ઇન્ટરનેટ પર લાઈવ મૂકવાના સ્ટેપ્સ (Deployment)

આ વેબસાઈટ સિંગલ પોર્ટ પર ચાલે છે (એક્સપ્રેસ બેકએન્ડ + રીએક્ટ ફ્રન્ટએન્ડ એકસાથે), તેથી Render અથવા Railway પર મફતમાં સરળતાથી લાઈવ કરી શકાય છે.

### પદ્ધતિ ૧: Render.com પર મૂકવું (સૌથી સરળ - Free)
1. તમારા આ પ્રોજેક્ટને [GitHub](https://github.com) પર અપલોડ (Push) કરો.
2. [Render.com](https://render.com) પર ફ્રી એકાઉન્ટ બનાવો.
3. **"New +"** બટન દબાવીને **"Web Service"** પસંદ કરો.
4. તમારા GitHub રિપોઝીટરીને કનેક્ટ કરો.
5. નીચેની સેટિંગ્સ ભરો:
   - **Name:** `khata-vahi`
   - **Runtime:** `Node`
   - **Build Command:** `npm install --prefix server && npm install --prefix client && npm run build`
   - **Start Command:** `node server/server.js`
   - **Instance Type:** `Free`
6. **Environment Variables** માં ઉમેરો:
   - `NODE_VERSION` = `22`
   - `JWT_SECRET` = `tamaro-gupt-secret-key-12345`
7. **"Create Web Service"** પર ક્લિક કરો. ૨-૩ મિનિટમાં તમારી ખાતાવહી વેબસાઈટ લાઈવ થઈ જશે!
